# Distant Reading Analysis - Web Interface

This directory contains the interactive web interface for exploring the distant reading analysis results.

## Files

- `index.html` - Main web interface
- `styles.css` - Styling
- `app.js` - JavaScript functionality
- `analysis.json` - Analysis data generated by `analyze_texts.py`

## How to Use

Simply open `index.html` in any modern web browser. No server required!

```bash
# From this directory
open index.html

# Or on Linux
xdg-open index.html

# Or just double-click the file
```

## Features

### Home View
- **Tag Filtering**: Click on any tag to filter books by that category
- **Book Cards**: Click on any book card to view detailed analysis
- **Multiple Tag Selection**: Select multiple tags to see books matching any of them

### Book Detail View
- **TF-IDF Distinctive Words**: The most characteristic words for each text
- **VADER Sentiment Analysis**: Compound, positive, negative, and neutral scores
- **Style Metrics**: Word counts, vocabulary richness, readability scores, and more
- **Part-of-Speech Distribution**: Visual chart showing POS tag frequencies
- **Top Frequent Words**: Bag of words with frequency counts

### Comparison View
- **Multi-Select**: Choose 2 or more books to compare
- **Sentiment Comparison**: Visual chart comparing sentiment across texts
- **Style Metrics Table**: Side-by-side comparison of all metrics
- **Vocabulary Overlap**: Common words appearing in all selected texts

## Generating New Analysis

To regenerate the analysis data with new books:

```bash
# From the project root directory
python analyze_texts.py
```

This will create a new `analysis.json` file with updated data.
